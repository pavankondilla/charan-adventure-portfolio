Generated with the built-in image generation tool. These are painted PNG sprites; character bodies are not SVG, HTML, or CSS drawings. No portrait was supplied, so the traveler is a fictional illustrated avatar, not a claimed likeness.

- `traveler-ghibli-v3.png`: six poses, three outfits, one consistent traveler; 3 columns × 2 rows. Top row walks, bottom row greets.

The source alpha is preserved. Transparent pixels can contain colored RGB data, which is invisible when composited correctly. `character-art.js` stores previously measured visible bounds for rendering and grounding. It does not read canvas pixels at runtime, allowing direct file opening.
